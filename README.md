# Измерение скорости скачивания

Требуется Node.js 24 или новее.

```sh
node download-speed.mts 'https://example.com/large-image.jpg'
```

На каждый запрос отводится 15 секунд, включая подключение и чтение всего тела ответа. При таймауте скрипт выводит номер запроса и завершается с кодом 1.
Измеряется средняя скорость последовательного скачивания с конкретного URL, а не универсальная скорость интернет-соединения.
